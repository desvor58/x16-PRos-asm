## Dependencies
Весь проект написан под компилятор *ia16-gcc* так что для начало установите его:

arch
```bash
yay -S gcc-ia16
```

debian
```bash
sudo apt install gcc-ia16-elf
```

Red Hat
```bash
just build from source :)
```

Для работы скрипта форматирования в *.ple* вам понадобиться бибилиотека pyelftools

Если вы не на debian то все просто:
```bash
pip install pyelftools
```

В ином случае вам придеться создать изолированое окружение:
```bash
sudo apt install python3-venv
python3 -m venv .venv
source .venv/bin/activate
pip install pyelftools
```

---

Если требуется просто *.ple* прогрмма то используете all задачу make'а
```bash
make
```
Скрипт сборки форматат так же даст вам информацию о используемых им секциях и итоговый размер.

Для быстрых тестов есть специальная задача *run*.

В makefile в начале есть переменная *PROS_DIR* её значение замените на путь до своей папки с x16-PRos.

Так же вы можете сменить флаги сборки PRos через переменную *PROS_BFLAGS*


# Using prstd in your project
Для получения статической бибилиотеки для линковки вызовите соответсвую задачу у make
```
make prstd
```

После этого в папке ```lib/prstd/``` будет файл ```libprstd.a``` - статическая библиотека.

prstd переопределяет точку входа _cstart, поэтому в link-скрипте вашего проекты вы должны это явно указать
```ld
ENTRY(_cstart)
```
А в секциях в *.text* ```.text.cstart``` должна быть первой
```ld
SECTIONS
{
    .text : {
        *(.text.cstart)
        # все остальное
    }
}
```
